# Sitar documentation

This folder holds everything documentation-related for Sitar.

- **`docs_source/`** -- the MkDocs source pages (`.md` files, hooks, stylesheets, embedded `.sitar` examples).
- **`mkdocs.yml`** -- the MkDocs site configuration.
- **`generated_site/`** -- the built static site (regenerated by `mkdocs build`, not tracked in git).
- **`sitar_pygments_lexer/`** -- a custom Pygments lexer providing syntax highlighting for Sitar code blocks in the generated site.
- **`documentation/`** -- the user manual, publications, and slides.

The site itself is built with MkDocs. The build needs Python 3 and a few packages, all listed in `docs_source/requirements.txt`.

Commands below use two working directories:

- Run `pip` commands from `docs/docs_source/` (where `requirements.txt` lives).
- Run `mkdocs` commands from `docs/` (where `mkdocs.yml` lives).

## One-time setup

From this `docs/` directory:

```sh
python3 -m venv .venv
```

Activate the virtualenv (do this once per shell session):

```sh
source .venv/bin/activate
```

Install the dependencies. This also pulls in the custom Pygments lexer used for Sitar syntax highlighting (the `-e ../sitar_pygments_lexer` line inside `requirements.txt`):

```sh
cd docs_source
pip install -r requirements.txt
cd ..
```

## Build the static site

With the venv active, from this `docs/` directory:

```sh
mkdocs build
```

The output goes to `generated_site/`.

## Preview locally

With the venv active, from this `docs/` directory:

```sh
mkdocs serve
```

Then open the printed localhost URL in a browser. Pages rebuild live as you edit files under `docs_source/`.

## Done for the day

```sh
deactivate
```
