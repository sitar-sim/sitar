# Grammar

- **`sitar.g`** -- the ANTLR grammar for the input system description.
- **`output_template.g`** -- the ANTLR grammar for a string-template-like construct used to generate C++ code after parsing the system description.

## Note

The ANTLR grammar `sitar.g` has been converted into EBNF and railroad-diagram notation automatically, using an online tool written by Gunther Rademacher, available at:

- <http://bottlecaps.de/convert/>
- <http://bottlecaps.de/rr/ui>

| Form | File |
|---|---|
| Original ANTLR notation | `sitar.g` |
| EBNF | `sitar_ebnf_syntax.txt` |
| Railroad diagram | `sitar_syntax_diagram.xhtml` |
